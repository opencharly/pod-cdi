# 2026.326.1530 — feat(pins)!: arch import moves to the release where aur is a routed builder

## Summary

`aur` became a routed builder, not a box `build:` format, in opencharly/distro-arch#77 (tagged `v2026.326.1455`). This repo's `arch:` import moves to that release, so the namespace it declares is the released, unified one:

- `charly.yml`: `arch:` `v2026.325.1112` → `v2026.326.1455`.

Nothing else changes; this repo's own boxes and candies are untouched.

**What this move does and does not do here — measured, because an earlier revision of this body claimed otherwise.** It does NOT change this repo's `charly box validate`: both trees report the same clean corpus (both transcripts below). What it changes is the vocabulary the import DECLARES — the pre-bump tag's `arch-test` is a document the current schema refuses, and this repo's resolved box set includes `arch.arch-test` — but `box validate` does not surface that, so this repo's validate is green on either pin. That gap is filed: **opencharly/plugin-box#95**. Without the bump this repo would keep declaring an `arch-test` that cannot be built, with nothing in its own gate saying so.
